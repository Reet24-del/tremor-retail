# Data sources

All data in this repository is **synthetic**, generated by `scripts/generate_demo_data.py` and `scripts/generate_demo_invoices.py` with a fixed seed (26). Regenerate with `make data`.

## Store

Gupta General Store, Indira Nagar, Lucknow (fictional). 34 products, 3 suppliers, 27 Jun to 24 Sep 2026.

## Files

| File | Contents |
|---|---|
| `sales_stock.csv` | 3,060 daily rows: transaction_id, date, product, quantity sold, selling price, opening/closing stock, damage, returns |
| `invoices/*.pdf` | Shakti Wholesale (SW-112, SW-151, SW-184), Awadh Grain Traders (AGT-0714, AGT-0802, AGT-0820B bulk, AGT-0911), Metro FMCG (MFD-3301, MFD-3388, MFD-3452) |
| `cached_extraction/*.json` | Validated extraction per invoice; used only for the sample run and always re-verified against the PDF text |
| `calendar.json` | Oil promotion 1–5 Jul (INR 129), festival week 7–16 Aug |
| `labels/signals.json` | 5 planted signals and 2 decoys |
| `labels/product_matches.json` | Invoice description → product id (null = must stay unmatched) |
| `labels/invoices_truth.json` | Ground-truth invoice fields for extraction accuracy |
